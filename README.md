# Сортировка больших файлов (External Sort)

## Цель работы
Освоить методы обработки данных, превышающих объём оперативной памяти, путём реализации алгоритмов **внешней сортировки**. Получить практические навыки работы с текстовыми и структурированными файлами на языках **C++** и **Python**, а также провести сравнительный анализ производительности реализованных решений.

---

## Постановка задачи

### 1. Подготовка данных
- Выбрана предметная область и согласована структура сортируемого файла.
- Реализован модуль-генератор, создающий текстовый файл `data.csv` (разделитель `,`) объёмом **1 ГБ**.

### 2. Внешняя сортировка
Реализованы модули `external_sort` на **C++** и **Python**

**Функциональные требования:**
-  Возможность выбора ключа (столбца) для сортировки.
-  Ограничение потребления RAM: **≤ 10%** от размера исходного файла.
-  Автоматическое удаление временных файлов после завершения работы.
-  Встроенная оценка времени этапов `разбиения` (split) и `слияния` (merge).
-  Общее время сортировки: **≤ 10 минут**.

**Технические особенности:**
- **C++:** использованы низкоуровневые модули `cstdio` / `fstream` для эффективного I/O.
- **Python:** менеджеры контекста (`with open(...) as f`) + библиотека `csv` с построчным/блочным чтением.

### 3. Графический интерфейс (GUI)
- Генерация тестовых данных.
- Выбор входного файла и ключа сортировки.
- Запуск алгоритма (C++ или Python).
- Валидация результата: интерактивный просмотр начальных, конечных и случайных частей отсортированного файла.
